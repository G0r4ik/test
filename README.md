# Тестовое

простое веб-приложение, которое позволяет пользователю отображать и фильтровать список пользователей.

Требования:

1. Добавьте возможность загрузки фотографии для каждого пользователя. (Инструкции по выполнению:
2. Расширьте данные о каждом пользователе, добавив поле для URL изображения или возможность загрузки файла с фотографией.
3. Визуально отобразите фотографию пользователя рядом с его данными.
4. Реализуйте функционал, который позволит пользователю загрузить фотографию для каждого пользователя.
5. Убедитесь, что фотографии корректно отображаются на странице и сохраняются вместе с данными пользователя.)
6. Реализуйте адаптивный дизайн, чтобы приложение хорошо выглядело на мобильных устройствах.
7. Опубликуйте ваше веб-приложение на GitHub Pages или любом другом хостинге.
